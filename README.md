Korea in Numbers is a terminal-style explorer of the Republic of Korea's official statistics: GDP, prices, labour, demographics and trade, with interactive charts, a sortable registry and CSV export. Every figure names its source and year, drawn from the Ministry of Data and Statistics, the Bank of Korea and the Ministry of Trade, Industry and Resources.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a browser. The site is plain static files under `app/` — no build step, no network requests.
